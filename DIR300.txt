Цель прожекта: спасти из мусорного ведра ролтон типа дир300, поставить вторым после провайдерского (как вариант), и подключаясь через него получить необходимый минимум для хоум-юсера/сохо:
- Чистый, неотравленый DNS, без подмен провайдером, через DNSCrypt
- Видосики с ютупа в 4к через дурилку поганых депеёв nfqws v71.4
- Повозка через AmneziaWG/WireGuard обёрнутый дурилкой
- Поддержка работы продуктов МакроСлоп (vlmcsd)
-- OpenSSL v1.1.1w + Elliptic Curves (используется только вайваем)
-- ShortcutFE + IPSet + Language EN+RU
После запуска со сбросом настроек - всё должно работать само по себе (не считая WG конечно).

Больше сюда ничего не влезет кмк, но этим уже можно пользоваться. Остаются только затраты на впску с wg, но это можно поднять на чём угодно, если там запустится дум - значит там будет и работать и wg, дешевле наверно ничего не придумать.

Для максимально дешёвого решения по объединению сетей в сборке есть клиент AmneziaWG, он работает и как клиент для простого WG, отличается только большей многословностью в логе и отсутствием сервера на этом же устройстве, ну и жрёт мозги примерно на метр больше. Да, у большинства провов и опсосов WG давно забанен, но можно обернуть его трафик дурилкой, записать настройки, перезапустить если не завелось сразу - и всё начинает работать.

Если AWG/WG работает на нестандартном порту, то в стратегиях nfqws надо добавить этот порт в блоке для WG (он почти в конце), и сеть скорее всего зашевелится, если конечно сам сервер не забанен по IP, но тут уж сами понимаете - всё для нашей безопасности, искренняя благодарность им за это.

По умолчанию роутится в объединённую сеть только CIDR Повозки, плюс ifconfig.me для быстрой проверки работоспособности этой сети в соседней вкладке. Внутри в комментарии всё есть.

Применённые настройки по дефолту:
- admin без пароля
- Часовой пояс MSK-3
- Точно доступные NTP-серверы
- Wi-Fi 2.4/5 скрыты, регион RU
- Сдвиг дефолтной подсети на 192.168.10.1
- Перенаправление всех клиентских запросов DNS на ролтон
- Включен строгий порядок DNS
- Отключена запись истории трафика (rstats)
- Добавлен скрипт для авто-"перезапуска" AWG/WG при проблемах со связью
- Минимизирована запись во флеш, сохранение только руками!

Чтобы всё это влезло в 4мб на дир300 - пришлось почистить, убраны:
- Лишние иконки + QR + DDNS + KABiNET
- Древние конфиги терминала
- Оптимизированы жырные картинки
- Начальные пробелы из ASP, JS и CSS
- Всякое про работу с дисками/модемами/принтерами
- wpa_supplicant (802.1X EAP на WAN, для Wi-Fi не используется)
- модули hash_ip, hash_net, hash_ipport и list_set
- lld2d и неиспользуемые утилиты отладки
- комментарии в services и protocols
- текстовые описания в dnscrypt-resolvers.csv
